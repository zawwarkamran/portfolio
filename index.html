Attune — Abnormal's behavioral foundation model

This is the project that ties the whole throughline together: I owned it end to end — data pipelines, the SQL warehouse layer, training, deployment, and inference monitoring, not just the model architecture.

Attune unifies identity, behavioral, and content signals into one multimodal model, trained on Spark/Databricks pipelines over multi-terabyte datasets. It now powers 85% of detections across Abnormal's platform, with meaningfully higher precision than the single-signal models it replaced.

Independent project — Flash-ML, Co-founder

Co-founded an agentic platform where an LLM agent actually does ML work — exploring data, building features, running and evaluating experiments — instead of just generating code you paste into a notebook. Took it through Y Combinator's application process and landed in the top 5% of applicants.
